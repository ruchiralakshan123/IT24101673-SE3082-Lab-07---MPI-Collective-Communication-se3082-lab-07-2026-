Notes:
- MPI_Scan computes an INCLUSIVE prefix sum: each rank receives the
  cumulative sum of all local_sums from rank 0 through its own rank.
- Every rank gets a DIFFERENT result (unlike Allreduce).
- sum_before_me = prefix_sum - local_sum acts as a global offset,
  enabling globally-correct running totals within each chunk.
- Verification formula: K*(K+1)/2 where K = (rank+1)*chunk_size.

  Rank 1: K=500000  => 125,000,250,000 ✓
